Create a vault

One transaction from your NEAR wallet creates <name>.styx-vaults.testnet, owned by you. It has no access keys, so nobody, the factory included, can replace its code or move its funds; it only adds the restricted agent keys you configure. The deposit pays for the vault's code storage and the agent's gas.

    Sentinels

    A sentinel watches the vault's payments and may pause it. Its key is a function-call key on the vault allowed only sentinel_pause: NEAR refuses it anything else, so it cannot pay, unpause, withdraw or change a rule. Only you unpause.     Change rules

    Amounts use six token decimals. Preview the exact method, base units and attached NEAR before signing.

    Add an agent key

    Generate a new ed25519 key in this browser and download it once. The private key only exists in the browser and the download; it is never sent to this app's server or saved in browser storage. Keep the download safe.

    Configure the public key below to install it on the vault as a function-call key restricted to pay, pay_with_exception and post_record. It cannot change rules or withdraw.
