## Imported crates and packages

| Path | Package | Description |
| --- | --- | --- |
| `sdk/core` | `erebus-core` | Canonical agreement and shared protocol types: chain-neutral, no Starknet dependency |
| `sdk/journal` | `erebus-journal` | Durable operation-journal storage for settlement backends: chain-neutral |
| `sdk/coordinator` | `erebus-coordinator` | Durable agreement intent and spending-policy coordination |
| `sdk/transport` | `erebus-transport` | Offchain Eleusis transport: Noise sessions, authenticated transcripts and a ciphertext relay |
| `sdk/evm` | `erebus-evm` | EVM public-bound settlement adapter: authorized agreement to on-chain payment |
| `sdk/py` | `erebus-sdk` | Thin Python binding over the Erebus Rust client, with no protocol logic |
| `mcp-server` | `erebus-mcp-server` | MCP server exposing Erebus tools to any agent framework |
| `contracts/evm` | Foundry project, no package name | EVM settlement contracts, including `ErebusSettlement` |

## Imported files changed before the import commit

The import commit is not byte-identical to the source commit. Before committing to this public repository, on 6 November 2026, we removed test keys so the history never contains them. No non-test behaviour changed. These edits are event-time work that sits inside the import commit.

| Removed | File | Effect |
| --- | --- | --- |
| Anvil default keys | `sdk/evm/tests/local_chain.rs`, `sdk/evm/tests/support/funded_faults.rs`, `sdk/evm/tests/x402_permit2_chain.rs`, `sdk/evm/tests/x402_service_models.rs` | Tests that need funded Anvil accounts read `EREBUS_TEST_ANVIL_KEY_0` to `_2` at runtime. One test that never touches a chain uses arbitrary keys instead. |
| Anvil account 1 key | `sdk/evm/src/chain/transaction.rs`, in `#[cfg(test)]` only | Replaced with an arbitrary test key. The `cast` known-answer vector and expected sender were regenerated with Foundry. |
| `private_key` fields | `sdk/evm/tests/fixtures/x402-permit2-vectors.json`, its generator's output, `sdk/evm/tests/x402_vectors.rs` | The test recovers the owner from the pinned reference signature. It no longer checks that local signing reproduces those bytes. |
| `testOnlySeeds` | `sdk/core/tests/fixtures/agreement-suite2-vector.json`, `sdk/core/tests/shielded_vectors.rs` | The test verifies the pinned circomlib signatures. It no longer checks key derivation or signing against them. The test is renamed `circomlib_signatures_verify_in_rust_for_both_roles`. |
| `spendSecretHex` | `sdk/core/tests/fixtures/m5-note-vector.json`, `sdk/core/tests/shielded_notes.rs`, `.gitleaks.toml` (allowlist entry) | Commitments and roots are still checked. Spend-tag and nullifier derivation are no longer checked against the vector. |

Arbitrary low-entropy test keys and seeds remain in imported tests, for example `[0x15; 32]`, `[seed; 32]`, `0xA11CE`, and the key bytes in the x402 vector generator. They hold no funds and are not listed exhaustively here.
