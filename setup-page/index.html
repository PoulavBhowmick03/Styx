Is your money protected?

The vault protects only the USDC inside it. USDC left in the agent's wallet, or in any wallet the agent controls, is covered by no rule: the agent can send it anywhere. Move your funds into the vault and leave the agent's address with gas only.

    3. Limits

    The daily limit is the most the agent can pay in a day without your signature. The per-payment limit does not stop splitting: with a 1 USDC per-payment limit, six payments of 1 USDC to an allowed vendor are each within the limit and together spend 6 USDC, with no approval asked. So set the daily limit to the amount you would accept losing in a day. The per-payment limit decides only which single payments ask you first.

    Ready to pay?

      A. Vault daily cap

      The vault's daily cap starts at 0, and while it is 0 no agent can pay anything. It is the most all agents together can pay in one UTC day, exceptions included, on top of each agent's own daily limit. Changing it takes effect at once and does not cancel approvals already signed.

      B. Agents

      Each agent has its own limits and its own off switch. Changing one agent does not cancel approvals that are waiting for other agents. It does cancel approvals already signed for that same agent, which then has to ask again. An agent address cannot also be an approver, and the owner cannot be an agent.

        C. Approvers

        An approver signs exceptions from their own wallet. An approver can authorize an exception for any enabled agent, with no budget of their own: an exception lifts only the per-payment limit, and the agent's daily limit and the vault's daily cap still apply. The owner is always an approver and is not listed.

          4. Vendors

            Only needed for the config file, which is the way to approve on a copy of the approval page that is not connected to a relay. On the hosted pages, section 7 sets approvals up without a file. The approval page sends your signature only to the relay named in your config, so a crafted link cannot redirect it. Leave this empty to carry signature files by hand.

            5. Move money into the vault

            Funds go in through the USDC token's transfer, the only way this vault can receive them. Send the agent's address only what it needs for gas.

            Use this section, not your wallet's Send button. A plain send to the vault's address fails and costs you gas, because the vault cannot receive one.

            This vault's code does not match the build this page deploys, so funding is switched off. A link or a mistyped address can lead to someone else's contract. Only unlock it if someone you trust has reviewed this vault's code.

            6. Pause and withdraw

            Pausing stops the agent's payments at once. Money stays in the vault.

            7. Approve exceptions from alerts

            1. Your agent asks for an exception, and you get an alert with a link.
            2. Open the link where your wallet is. In this browser it goes straight to review. On a phone the approval page asks you to connect your wallet first, and checks that it is the owner's.
            3. Check the recipient and the amount, then sign with the owner's wallet. No file is needed.

            Only this vault's owner wallet can sign. Changing limits or vendors cancels approvals that are waiting, so the agent has to ask again.
